MCP Server Installation and Configuration

Option 1: Local Connection (stdio) - Recommended

This is the recommended configuration for local use. The MCP server communicates directly with the client through standard input/output.

📦 Step 1: Build the project

npm run build

⚙️ Step 2: Configure the MCP client

Add this configuration to your MCP config file (for example, ~/.gemini/antigravity/mcp_config.json): 

{
  "mcpServers": {
    "akuri-core": {
      "command": "node",
      "args": [
        "/mnt/0e67f549-8f2b-4fee-92ea-605bc0fd16ea/MULTIROOT/akuri-acp/dist/main.js"
      ],
      "env": {
        "NODE_ENV": "production",
        "MCP_MODE": "true"
      }
    }
  }
}

🔄 Step 3: Restart the client

Restart your MCP client (Antigravity, Claude Desktop, etc.) to detect the new configuration.

💡 Important: Make sure the path to the main.js file is correct on your system. Replace the example path with your actual path.

Option 2: Remote Connection (HTTP/SSE)

If you prefer to connect via HTTP (useful for development or remote access), use this configuration. First start the server with npm run start:prod. 

{
  "mcpServers": {
    "akuri-remote": {
      "serverUrl": "http://localhost:3001/mcp/sse-connect",
      "headers": {
        "Content-Type": "application/json"
      }
    }
  }
}

📋 Prerequisites

  • Node.js v18 or higher
  • NPM or PNPM installed
  • Read/write access to the working directory

✅ Verification

Once configured, restart your MCP client. If the connection is successful, you will see the status "Connected" and will have access to 3 tools:

  • akuri_search_docs
  • akuri_check_workflow
  • akuri_generate_blueprint
