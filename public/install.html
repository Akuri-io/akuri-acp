Instalación y Configuración del Servidor MCP

Opción 1: Conexión Local (stdio) - Recomendada

Esta es la configuración recomendada para uso local. El servidor MCP se comunica directamente con el cliente a través de entrada/salida estándar.

📦 Paso 1: Compilar el proyecto

npm run build

⚙️ Paso 2: Configurar el cliente MCP

Agrega esta configuración a tu archivo MCP config (por ejemplo, ~/.gemini/antigravity/mcp_config.json): 

{
  "mcpServers": {
    "akuri-core": {
      "command": "node",
      "args": [
        "/mnt/0e67f549-8f2b-4fee-92ea-605bc0fd16ea/MULTIROOT/akuri-acp/dist/main.js"
      ],
      "env": {
        "NODE_ENV": "production",
        "MCP_MODE": "true"
      }
    }
  }
}

🔄 Paso 3: Reiniciar el cliente

Reinicia tu cliente MCP (Antigravity, Claude Desktop, etc.) para que detecte la nueva configuración.

💡 Importante: Asegúrate de que la ruta al archivo main.js sea correcta en tu sistema. Reemplaza la ruta del ejemplo con tu ruta real.

Opción 2: Conexión Remota (HTTP/SSE)

Si prefiere conectar vía HTTP (útil para desarrollo o acceso remoto), use esta configuración. Primero inicie el servidor con npm run start:prod. 

{
  "mcpServers": {
    "akuri-remote": {
      "serverUrl": "http://localhost:3001/mcp/sse-connect",
      "headers": {
        "Content-Type": "application/json"
      }
    }
  }
}

📋 Requisitos Previos

  • Node.js v18 o superior
  • NPM o PNPM instalado
  • Acceso de lectura/escritura al directorio de trabajo

✅ Verificación

Una vez configurado, reinicie su cliente MCP. Si la conexión es exitosa, verá el estado "Conectado" y tendrá acceso a 3 herramientas:

  • akuri_search_docs
  • akuri_check_workflow
  • akuri_generate_blueprint
