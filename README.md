
# 🧠 Akuri Context Protocol (ACP)

> **Smart Context Server & Workflow Enforcer for AI Agents**

**Akuri Context Protocol** is an **MCP (Model Context Protocol)** compatible server built with **NestJS**. It acts as the "methodological brain" connecting your local file system (documentation, guidelines, and work docs) with AI Agents like **Cursor**, **Windsurf**, **Kilo Code**, or **Claude Desktop**.

Unlike a simple file searcher, ACP understands the **Akuri Methodology**: it knows you cannot execute a `BUILD` phase without an approved `PLAN`, and it ensures code consistency by automatically injecting project guardrails into prompts.

---

## ✨ Key Features

### 1. 📚 The Librarian (Intelligent Search)
- **Real-Time Indexing:** Uses `chokidar` to watch your knowledge base for changes instantly.
- **Hybrid Search:** Powered by **Orama** (in-memory vector/full-text DB) for semantic retrieval of local Markdown guides.
- **Metadata Aware:** Parses and filters based on YAML Frontmatter (tags, status, use_case, layers).

### 2. 👮 The Workflow Engine (Process Control)
- **Dependency Validation:** Prevents the AI from generating code out of order.
- **Strict Rules Enforcement:**
  - `PLAN` requires an existing `DESIGN` document.
  - `BUILD` requires existing `DESIGN` + `PLAN` documents.
  - `REFACTOR` requires an existing `AUDIT` document.

### 3. 🏗️ The Architect (Consistent Generation)
- **Blueprints:** Batch prompt generation based on `.md` templates and JSON variables.
- **Automated Guardrails:** Automatically appends "Naming Conventions" and "Golden Rules" to the end of every generated prompt, ensuring every piece of code follows the exact same standard.

## 🛠️ Installation & Setup

### Prerequisites
- Node.js v20+
- A local folder containing the Akuri documentation structure (`akuri-guidelines`, `akuri-work`, etc.).

### 1. Clone and Install
```bash
git clone <repo-url>
cd akuri-context-protocol
npm install
```

### 2. Path Configuration
The system needs to know where your documentation lives.

**Required Environment Variable:**
```bash
AKURI_DOCS_PATH=/path/to/your/akuri/documents
```

> **Important:** This environment variable is now **required**. The application will fail to start without it. Copy `.env.example` to `.env` and configure the path.

### 3. Build
Since MCP runs the compiled code, it is vital to run the build command after any change:
```bash
npm run build
```

## 🔌 Integration with AI Agents

To connect this server with **Cursor**, **Windsurf**, or **Kilo Code**, you must edit your IDE's MCP configuration file.

**Configuration (`mcpServers`):**

```json
{
  "mcpServers": {
    "akuri-core": {
      "command": "node",
      "args": ["/absolute/path/to/your/repo/dist/main.js"],
      "env": {
        "NODE_ENV": "production"
      }
    }
  }
}
```
*Make sure to use the absolute path to the `dist/main.js` file generated by the build.*

## 🧰 Available Tools (MCP Tools)

The server exposes the following tools to the AI Agent. **Note:** Document search functionality is only available through MCP tools, not REST endpoints.

### `akuri_search_docs`
Retrieves information from the local knowledge base.
- **Params:** `query` (string), `limit` (number).
- **Usage:** "Search for how to implement Tailwind v4 in Angular".
- **Important:** This is the only way to search documents. REST endpoint `/paths/search` has been removed to avoid duplication.

### `akuri_check_workflow`
Validates if the user has methodological permission to start a phase.
- **Params:** `intent` ('PLAN' | 'BUILD' | 'REFACTOR'), `feature_context` (string).
- **Usage:** "I want to start the BUILD phase for the login feature. Check if I can proceed."
- **Return:** Approved or Blocked (listing missing documents).

### `akuri_generate_blueprint`
Generates a structured prompt based on a master template.
- **Params:** `blueprint_name` (string), `variables` (JSON string).
- **Usage:** "Generate the users table using the 'datatable' blueprint".

## 🌐 REST API Endpoints

In addition to MCP tools, the server provides REST API endpoints for system monitoring and administration.

### System Information
- **`GET /`** - Returns comprehensive system information including version, uptime, memory usage, and available endpoints.

### Admin API (`/api/admin/*`)
- **`GET /api/admin/stats`** - System statistics (documents indexed, memory usage, uptime).
- **`GET /api/admin/extensions`** - List of available MCP extensions.
- **`GET /api/admin/config`** - Current system configuration.
- **`POST /api/admin/config`** - Update system configuration.

### Legacy Admin Interface
- **`GET /admin`** - HTML dashboard (maintained for backward compatibility).
- **`GET /admin/extensions`** - HTML extensions page.
- **`GET /admin/install`** - HTML installation page.
- **`GET /admin/paths`** - HTML paths management page.

### Health & Monitoring
- **`GET /health`** - Basic health check.
- **`GET /health/detailed`** - Detailed health information.

### Paths Management
- **`GET /paths`** - List configured document paths.
- **`POST /paths`** - Add new document path.
- **`PATCH /paths/:id`** - Update document path.
- **`DELETE /paths/:id`** - Remove document path.
- **`POST /paths/validate`** - Validate document path configuration.

**Response Format:** All REST endpoints return standardized JSON responses with `success`, `data`, `message`, and `timestamp` fields.
